# Data dictionary

Every table and column of the gold database (`data/gold/udise.duckdb`, also exported to `data/gold/parquet/`). Generated by `scripts/make_data_dictionary.py` from the database itself; row counts are from the last full run.

Star schema: facts hold the measures at a stated grain and point to dimensions through integer surrogate keys. `dim_school` is a Type 2 slowly changing dimension: facts join to the school version valid in that year, so a school that moved district (e.g. ALWAR -> KOTPUTLI-BEHROR) is counted in the right district each year.

## dim_year

Dimension. Grain: one row per academic year. Rows: 2.

| Column | Type | Description |
|---|---|---|
| `year_key` | INTEGER | Surrogate key of dim_year. |
| `academic_year` | VARCHAR | Academic year, e.g. 2024-25. |
| `start_year` | INTEGER | First calendar year of the academic year. |

## dim_district

Dimension. Grain: one row per district (41). Rows: 41.

| Column | Type | Description |
|---|---|---|
| `district_key` | INTEGER | Surrogate key of dim_district. |
| `district_name` | VARCHAR | District, canonical spelling. |
| `aliases` | VARCHAR[] | Other spellings used by the portal in some years (e.g. JALOR). |

## dim_management

Dimension. Grain: one row per UDISE+ management code, plus key 0 = unmapped. Rows: 14.

| Column | Type | Description |
|---|---|---|
| `management_key` | INTEGER | Surrogate key of dim_management (0 = code not in the reference). |
| `management_code` | BIGINT | UDISE+ management code (column `managment` in the source). |
| `management_group` | VARCHAR | Management group: State / Central / Other Government, Private Unaided, Other Non-Government, or Unmapped. |
| `is_government` | BOOLEAN | True for the three government groups (validated against official totals). |

## dim_school

Dimension, SCD Type 2. Grain: one row per version of a school's attributes. Rows: 109,037.

| Column | Type | Description |
|---|---|---|
| `school_key` | INTEGER | Surrogate key of dim_school: one school VERSION (SCD2), not one school. |
| `pseudocode` | BIGINT | UDISE+ pseudonymised school code; stable across years. |
| `version` | INTEGER | Version number of the school's attributes (1, 2, ...). |
| `valid_from_year` | INTEGER | First start year in which this version applies. |
| `valid_to_year` | INTEGER | Last start year in which this version was observed. |
| `is_current` | BOOLEAN | True for the school's latest version. |
| `district_key` | INTEGER | Surrogate key of dim_district. |
| `block` | VARCHAR | UDISE+ block name (upper case). |
| `block_clean` | VARCHAR | Block, blank where the block is an admin region (e.g. JAIPUR REGION). |
| `management_key` | INTEGER | Surrogate key of dim_management (0 = code not in the reference). |
| `rural_urban` | BIGINT | 1 = Rural, 2 = Urban. |
| `location` | VARCHAR | Rural or Urban. |

| `school_type_label` | VARCHAR | Boys / Girls / Co-educational. |

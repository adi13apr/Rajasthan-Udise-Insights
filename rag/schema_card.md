# Gold schema card (for the SQL tool)

Generated by `python -m rag.schema_card` from the gold DuckDB (star schema of UDISE+ school data, Rajasthan, all 41 districts, 2024-25 and 2025-26). Read this before writing SQL for `rag/sql_tool.py`.

## How to query

- One SELECT per call (CTEs, UNION and subqueries are fine), DuckDB dialect. Bare table names only: no schema prefix, no files, no table functions. Results are capped at 200 rows (LIMIT 200 is added if missing), so aggregate rather than list.
- The school code is hidden. School-level tables are for counting and aggregating; do not list or single out individual schools (UDISE+ data-sharing terms).
- Facts store `school_key`, the school *version* valid in that year (dim_school is SCD Type 2). Join `using (school_key)` with no year condition and the fact is placed in the right district for that year. Join `using (year_key)` to dim_year for the year.
- Counting schools: one row per school and year in int_school_year, fact_school_facilities and fact_teachers, so `count(*)` per year is the number of schools.
- Students: the official figure includes pre-primary (`enr_total + enr_pre_primary`, or all of fact_enrolment). `enr_total` and the marts' `enrolment` are classes 1-12 only.
- The marts leave out schools with no students in classes 1-12, so their `schools` is a little below the official count; use int_school_year for official totals.
- Government vs private: `is_government` (or `management_group`).
- Districts: 41, canonical upper-case names (`district_name`, `district` in the marts); dim_district.aliases holds other spellings (JALOR -> JALORE). 189 schools changed district between the years, 180 of them ALWAR -> KOTPUTLI-BEHROR, so compare those districts' year-on-year changes with care.
- Playground fell sharply in one year because of a reporting change: do not use it for trends (it is not in `infra_index`).
- In 2025-26, 114 central-government schools have block 'JAIPUR REGION'; `block_clean` is blank for them.
- Quote the source with any figure: "Source: UDISE+, Ministry of Education, Government of India".

## Tables

### int_school_year
Intermediate (school-level, never exported); grain: school x year; 212,747 rows. **Start here** for most questions: one row per school and year, already joined to district, management, location, enrolment by stage and sex, teachers and facilities.
Joins: `school_key` -> dim_school, `year_key` -> dim_year, `district_key` -> dim_district, `management_key` -> dim_management.
- `academic_year` text: Academic year, e.g. 2024-25.
- `district_name` text: District, canonical spelling.
- `management_group` text: Management group: State / Central / Other Government, Private Unaided, Other Non-Government, or Unmapped.
- `is_government` bool: True for State, Central and Other Government (see Codes).
- `location` text: Rural or Urban.
- `school_category` int: UDISE+ school category code; classes taught per code below (Codes).
- `enr_total` int: Students in classes 1-12.
- `enr_girls` int: Girls in classes 1-12.
- `enr_pre_primary` int: Students in pre-primary.
- `enr_primary` int: Students in classes 1-5.
- `enr_primary_b` int: Boys in classes 1-5.
- `enr_primary_g` int: Girls in classes 1-5.
- `enr_secondary_plus` int: Students in classes 9-12.
- `enr_secondary_plus_b` int: Boys in classes 9-12.
- `enr_secondary_plus_g` int: Girls in classes 9-12.
- `enr_sc` int: SC students in classes 1-12.
- `enr_st` int: ST students in classes 1-12.
- `total_tch` int: Teachers in the school.
- `single_teacher` int: 1 = exactly one teacher.
- Facility flags (double, 1 / 0 / NULL, see Codes): `has_electricity`, `has_safe_water`, `has_girls_toilet`, `has_boys_toilet`, `has_handwash`, `has_library`, `has_playground`, `has_ramp`, `has_internet`, `has_computer`
- `infra_index` decimal: Infrastructure index (0-100): share of 8 facilities present among those reported (electricity, safe water, girls' toilet, handwash, library, ramp, internet, computer).

### mart_district_year
Mart; grain: district x year; schools with no students in classes 1-12 excluded; 82 rows. District-level indicators (ratios and shares ready to use).
- `district` text: District, canonical spelling.
- `year` text: Academic year, e.g. 2024-25.
- `schools` int: Schools (with students in classes 1-12).
- `enrolment` int: Students in classes 1-12.
- `girls_share` double: Girls / students, classes 1-12.
- `girls_share_primary` double: Girls / students, classes 1-5.
- `girls_share_sec_plus` double: Girls / students, classes 9-12.
- `st_share` double: ST students / students.
- `sc_share` double: SC students / students.
- `teachers` int: Teachers.
- `ptr` double: Pupil-teacher ratio: students in classes 1-12 / teachers.
- `pct_single_teacher` double: Single-teacher schools (%).
- `avg_infra_index` double: Average school infrastructure index (0-100).
- `girls_retention_gap` double: girls_share_sec_plus - girls_share_primary. Negative: girls drop out more after class 8; positive: boys leave more (or girls stay more).
- `boys_progression` double: (Boys per grade in classes 9-12) / (boys per grade in classes 1-5).
- `girls_progression` double: (Girls per grade in classes 9-12) / (girls per grade in classes 1-5).
- Facility shares (double, %, among schools reporting it): `pct_has_electricity`, `pct_has_safe_water`, `pct_has_girls_toilet`, `pct_has_boys_toilet`, `pct_has_handwash`, `pct_has_library`, `pct_has_playground`, `pct_has_ramp`, `pct_has_internet`, `pct_has_computer`

### mart_district_year_management
Mart; grain: district x year x management group; same rules; 330 rows. The same indicators split by management group.
Same columns as mart_district_year, plus `management_group`, `is_government`.

### fact_enrolment
Fact; grain: school x year x grade x gender x social category; rows with 0 students omitted; 6,403,516 rows. Enrolment by grade, gender and social category (finest detail).
Joins: `school_key` -> dim_school, `year_key` -> dim_year, `grade_key` -> dim_grade, `gender_key` -> dim_gender, `social_category_key` -> dim_social_category.
- `students` int: Students (> 0; a missing row means 0). Sum over social categories for totals.

### fact_teachers
Fact; grain: school x year (the source is already one row per school); 212,747 rows. Teacher counts by sex, category, appointment, qualification, classes taught.
Joins: `school_key` -> dim_school, `year_key` -> dim_year.
- `total_tch` int: Teachers in the school.
- `flag_no_teachers_with_students` int: 1 = students in classes 1-12 but no teachers.
- `flag_high_ptr` int: 1 = pupil-teacher ratio above 60.
- Teacher counts (int, number of teachers in the school), by group:
  - by sex: `male`, `female`, `transgender`
  - by social category: `gen_tch`, `sc_tch`, `st_tch`, `obc_tch`
  - by appointment: `regular`, `contract`, `part_time`
  - highest academic qualification: `below_graduate`, `graduate`, `post_graduate_and_above`
  - highest professional qualification: `diploma_certificate`, `diploma_ele_edu`, `bachelor_of_ee`, `bed_equivalent`, `med_equivalent`, `early_childhood_tch`, `bed_nursery`, `diploma_special_edu`, `pursuing_rpc`, `other`, `none`
  - classes taught (pr = 1-5, upr = 6-8, sec = 9-10, hsec = 11-12; `class_taugt_...` is spelled so in the source): `class_taught_pr`, `class_taught_upr`, `class_taught_pr_upr`, `class_taught_sec_only`, `class_taught_hsec_only`, `class_taught_upr_sec`, `class_taught_sec_hsec`, `class_taugt_pre_primary_only`, `class_taught_pr_and_pre_pri`
  - training and duties: `trained_comp`, `trained_cwsn`, `teacher_involve_non_training_assignment`

### fact_school_facilities
Fact (periodic snapshot); grain: school x year; one row for every school-year; 212,747 rows. Facility flags, classrooms and toilets per school-year.
Joins: `school_key` -> dim_school, `year_key` -> dim_year.
- `lowclass` int: Lowest class taught.
- `highclass` int: Highest class taught.
- Facility flags (double, 1 / 0 / NULL, see Codes): `has_electricity`, `has_safe_water`, `has_girls_toilet`, `has_boys_toilet`, `has_handwash`, `has_library`, `has_playground`, `has_ramp`, `has_internet`, `has_computer`
- `classrooms` int: Classrooms, rebuilt as good + minor repair + major repair (total_class_rooms is 0 for almost every school in 2024-25).
- `classrooms_good` int: Classrooms in good condition.
- `classrooms_needs_minor_repair` int: No. of classrooms Need Minor repair in school
- `classrooms_needs_major_repair` int: No. of classrooms Need Major repair in school
- `pct_classrooms_major_repair` double: Share of classrooms needing major repair (%).
- `total_girls_toilet` int: No. of toilet seats available excluding CWSN friendly toilets for Total Girls in school
- `total_girls_func_toilet` int: No. of Functional toilet seats available excluding CWSN friendly toilets for Girls
- `total_boys_toilet` int: No. of toilet seats available excluding CWSN friendly toilets for Total Boys in school
- `total_boys_func_toilet` int: No. of Functional toilet seats available excluding CWSN friendly toilets for Boys in school
- `flag_facility_invalid_code` int: 1 = a coded facility column has a code not in the schema (e.g. solar_panel = 3).
- `flag_functional_toilets_exceed_total` int: 1 = more functional toilets than toilets reported.
- `flag_classroom_total_mismatch` int: 1 = total_class_rooms filled in but different from the rebuilt count.

### dim_school

## Codes

- **Years** (dim_year): 1 = 2024-25, 2 = 2025-26. Filter with `academic_year = '2024-25'` (`year` in the marts).
- **Grades** (dim_grade): pre_primary: grade_key 0 (grade_code PP); primary: grade_key 1-5; upper_primary: grade_key 6-8; secondary: grade_key 9-10; higher_secondary: grade_key 11-12. Stages: primary 1-5, upper_primary 6-8, secondary 9-10, higher_secondary 11-12.
- **Gender** (dim_gender): 1 = B (Boys), 2 = G (Girls), 3 = T (Transgender). Transgender is reported only from 2025-26.
- **Social category** (dim_social_category): 1 = General, 2 = SC, 3 = ST, 4 = OBC. A complete split of enrolment.
- **Location**: `location` = 'Rural' / 'Urban' (`rural_urban` 1 = Rural, 2 = Urban).
- **School type**: 1 = Boys, 2 = Girls, 3 = Co-educational (`school_type_label`).
- **School category**: classes taught, the most common lowest-highest class per code in the data (the DCF names are not in the schema files): 1 = 1-5, 2 = 1-8, 3 = 1-12, 4 = 6-8, 5 = 6-12, 6 = 1-10, 7 = 6-10, 8 = 9-10, 10 = 9-12, 11 = 11-12, 12 = PP only.
- **Management** (dim_management; source column `managment`, spelled so): `is_government` = true for the three government groups.
  - Unmapped (non-government): codes none (key 0)
  - State Government (government): codes 1, 2, 3, 6, 90
  - Private Unaided (non-government): codes 5
  - Central Government (government): codes 92, 93
  - Other Government (government): codes 94, 95, 101
  - Other Non-Government (non-government): codes 97, 98
  - The codes are not documented in the schema PDFs. Codes 94, 95 and 101 were resolved as government using the official totals: counting them as government adds exactly the 7 schools and 170 teachers that were otherwise missing, so government teachers match the official 4,45,073 for 2024-25 (DATA_QUALITY_LOG #13). 97 and 98 are non-government. The exact names of 94, 95, 97, 98 and 101 are still to be confirmed with the UDISE+ DCF, so describe them only by their group.
- **Facility flags** (`has_*`): 1 = yes, 0 = no, NULL = not reported or not applicable (source code 9). Never count NULL as no: `avg(has_x)` gives the share among schools that reported it; `count(*) filter (where has_x = 0)` counts the noes. `pct_has_*` in the marts = 100 * avg(has_*). Meanings: electricity = electricity connection that works (code 1; 3 = not functional counts as no); safe_water = a functional safe drinking-water source (hand pump, protected well, tap, other, packaged); girls_toilet = at least one functional girls' toilet (incl. CWSN-friendly); boys_toilet = at least one functional boys' toilet (incl. CWSN-friendly); handwash = handwash facility near the toilets; library = library; playground = playground (dropped by a reporting change; not in the index); ramp = ramps for children with disabilities; internet = internet; computer = at least one laptop, desktop or tablet.

## Examples (question -> SQL)

1. How many schools, students (official definition, pre-primary included) and teachers did Rajasthan have in 2024-25?

```sql
select count(*)                            as schools,
       sum(enr_total + enr_pre_primary)    as students_incl_pre_primary,
       sum(total_tch)                      as teachers
from int_school_year
where academic_year = '2024-25'
```

2. Which five districts had the highest pupil-teacher ratio in 2025-26?

```sql
select district, ptr, enrolment, teachers
from mart_district_year
where year = '2025-26'
order by ptr desc
limit 5
```

3. How many girls were enrolled in classes 9-12 in each social category in 2024-25?

```sql
select sc.social_category, sum(f.students) as girls
from fact_enrolment f
join dim_year y             using (year_key)
join dim_grade g            using (grade_key)
join dim_gender ge          using (gender_key)
join dim_social_category sc using (social_category_key)
where y.academic_year = '2024-25'
  and g.stage in ('secondary', 'higher_secondary')
  and ge.gender_code = 'G'
group by sc.social_category
order by girls desc
```

4. In each district, how many government schools had no working electricity in 2025-26, and what share of the government schools that reported it is that?

```sql
select district_name,
       count(*) filter (where has_electricity = 0)         as schools_without_electricity,
       round(100 * (1 - avg(has_electricity)), 1)          as pct_without_electricity
from int_school_year
where academic_year = '2025-26' and is_government
group by district_name
order by schools_without_electricity desc
```

5. How did single-teacher schools change between 2024-25 and 2025-26, by management group?

```sql
select management_group,
       sum(single_teacher) filter (where academic_year = '2024-25') as single_teacher_2024_25,
       sum(single_teacher) filter (where academic_year = '2025-26') as single_teacher_2025_26
from int_school_year
group by management_group
order by single_teacher_2025_26 desc
```
